Use RxJS when

Multiple async sources interact over time: route plus form plus auth plus socket plus API. That is where cancellation, combination, multicasting, and backpressure operators earn their keep.

Use async/await when

A workflow is single-shot, sequential, and naturally request/response. In services, returning an Observable is still useful because Angular can cancel it and compose it with UI streams.

Senior review heuristic

Choose switchMap for replace-latest reads, concatMap for ordered writes, mergeMap for independent parallel work, and exhaustMap for submit guards. Most bugs come from choosing the wrong flattening policy.
