What is Debouncing?

Debouncing is a technique that delays the execution of a function until a specified time has elapsed since it was last invoked. In the context of API calls:

5 keystrokes = 1 API call 🟢 (after 400ms silence)
debounceTime(400) Emits a value only after 400ms have passed with no new emissions. Resets the timer on every new keystroke.
distinctUntilChanged() Skips the API call entirely if the value hasn't changed since the last emission. Prevents duplicate requests.
switchMap() Cancels the previous in-flight Observable when a new value arrives. Prevents race conditions and stale data.
