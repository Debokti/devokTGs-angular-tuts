Feature 01

Dependent Dropdown

Cascading select controls powered by Angular Reactive Forms. Each child dropdown is disabled and populated only after its parent is selected — simulating a KYC Address Form in a loan origination workflow.

How It Works

1
Country selected → valueChanges emits → resets state & city controls → calls GeoService.getStates() → on response, enables the State dropdown.
2
State selected → same pattern → calls GeoService.getCities() → enables City dropdown.
3
Parent changed mid-flow → child controls are immediately disabled and reset, preventing stale data from being submitted.
4
Memory leak prevention → all subscriptions piped through takeUntil(this.destroy$) — auto-unsubscribed on component destroy.
